# Dashboard (Web Presentation View)

An optional browser dashboard built with Next.js / React to mirror the FairScope mobile application research panels on large presentation displays during viva and conferences.

## Features

- Real-time or uploaded JSON benchmark inspection (`benchmarks/` and `results/`).
- Side-by-side comparison of baseline vs compressed model latency and memory usage.
- Fairness parity and disparity charts across Fitzpatrick skin types (I to VI).
- Grad-CAM heatmap overlays on test samples.

## Getting Started

```bash
npm install
npm run dev
```
