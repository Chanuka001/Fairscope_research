# Datasets & Data Storage

> **Important:** Do NOT commit raw image datasets or proprietary sensor recordings into this repository.

## Public Image Datasets

The image branch models utilize the following benchmark dermatological datasets:

1. **Fitzpatrick17k:** Dermatological conditions annotated with Fitzpatrick skin type (I to VI).
2. **ACNE04:** Standard facial acne grading dataset.
3. **DDI (Diverse Dermatology Images):** Dermatology images specifically collected to benchmark bias across diverse skin tones.
4. **HAM10000:** Benchmark pigmented skin lesions dataset.

## Sensor Data Collection & Ethics

Physical probe readings collected during laboratory testing or live evaluations:

- Must be collected with signed participant consent.
- Must be fully de-identified and anonymized.
- Should be stored locally or on secure university cloud storage according to ethics guidelines.
